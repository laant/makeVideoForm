# ink-theater 캐릭터 제작 규격 (새 캐릭터 납품용)

> 기준: ink-theater 기본 마스코트(`InkTheater.mascot()`, `OpenMontage/ink-theater/ink-theater.js`)
> 근거 규칙: `OpenMontage/skills/creative/ink-theater.md` · `skills/pipelines/character-animation/character-design-director.md` · 스키마 `character_design` / `rig_plan` / `pose_library`
> 함께 보는 파일: `mascot-template.svg`(부위·관절 템플릿) · `pose-sheet.png`(기본 마스코트 포즈 8종)

새 캐릭터는 **이 문서의 부위·관절·포즈를 빠짐없이** 갖추면, 지금까지 만든 장면(레버 당기기, 물건 나르기, 건반 누르기, 으쓱, 말풍선)에 그대로 바꿔 끼울 수 있습니다.

---

## 1. 그림체 규칙 (ink-theater 공통, 바꾸지 않음)

| 항목 | 규칙 |
|---|---|
| 색 | 검정 잉크 = 구조·캐릭터. 흰 종이 바탕. 강조색은 의미가 정해짐: 주황 = 흐름·화살표만 · 빨강 = 문제·경고 · 파랑 = 좋은 결과. 캐릭터 몸에는 색을 쓰지 않음 |
| 표정 | **무표정(deadpan)** — 눈은 흰 점 2개, 입 없음. "귀엽게" 만들지 않음(볼터치·큰 눈망울·웃는 입 X) |
| 실루엣 | 한 덩어리로 읽히는 단순한 검은 실루엣. 작게(화면의 10%) 보여도 알아볼 것 |
| 선 | 팔·다리는 둥근 끝 선(stroke). 손가락·발 모양 없음(선 끝이 곧 손·발) |
| 떨림 | 렌더 때 손그림 떨림(boil) 필터가 자동으로 걸림 — 일부러 삐뚤게 그릴 필요 없음 |
| 화면 비중 | 캐릭터+사물이 화면의 40~60%, 여백 35% 이상 |

## 2. 부위 (rig_plan.parts) — 반드시 따로 나뉜 7개

`mascot-template.svg` 의 그룹 id 를 그대로 씁니다. 좌표는 **scale 2 기준, 몸 중심 = (0,0)**.

| id | 종류 | 기본 마스코트 크기·위치 | 레이어(아래→위) | 부모 |
|---|---|---|---|---|
| `armL` | 2마디 팔(위팔+아래팔) | 어깨 (-56,-4), 위팔 64px + 아래팔 60px, 굵기 14 | 1 (몸 **뒤**) | body |
| `armR` | 2마디 팔 | 어깨 (56,-4), 같은 길이 | 2 (몸 **뒤**) | body |
| `body` | 몸통(머리 겸) | 타원 rx 80 · ry 100 | 3 | — |
| `legL` | 다리(선 1개) | 엉덩이 (-24,92)에서 48px, 살짝 바깥으로 | 4 | body |
| `legR` | 다리 | 엉덩이 (24,92)에서 48px | 5 | body |
| `eyeL` | 눈 | (-24,-32), 반지름 14, 흰색 | 6 | body |
| `eyeR` | 눈 | (24,-32), 반지름 14, 흰색 | 7 | body |

- **팔은 몸 뒤에 그려집니다.** 어깨가 몸 실루엣 안쪽에 있어서, 팔을 몸 앞(가운데)으로 모으면 몸에 가려집니다(포즈 시트 5번). 새 캐릭터도 같은 구조면 그대로 동작합니다.
- **팔은 IK(역운동학)로 움직입니다.** 손끝 목표점만 주면 팔꿈치가 자동으로 꺾입니다 → 팔을 **위팔·아래팔 두 마디의 선**으로 그려 주세요(한 장짜리 팔 그림은 IK 불가).
- 몸과 머리가 따로 있는 캐릭터라면 `head` 를 추가하고 부모를 `body` 로(고개 기울이기 가능). 목 위치를 관절점으로 표시.
- 소품(모자·가방·안경)은 별도 그룹, 부모 부위를 적어 주세요.

## 3. 관절점 (rig_plan.joints)

| 관절 | 좌표(scale 2) | 회전/이동 |
|---|---|---|
| body center | (0,0) | 몸 전체 이동·튀기기(걷기 bob)·기울이기 기준 |
| shoulderL / shoulderR | (∓56, -4) | 팔 IK 시작점 |
| elbow | 자동(IK) | 팔꿈치는 바깥·아래로 꺾임 |
| hipL / hipR | (∓24, 92) | 다리 회전 기준(걷기용, 현재 기본 마스코트는 다리 고정) |
| eye center | (∓24, -32) | 시선 이동(좌우 ±4), 깜빡임(세로 0.2배) |

새 캐릭터의 비율이 다르면 관절 좌표를 새 그림에 맞춰 알려 주시면 됩니다(위치는 달라도 **개수·종류는 같게**).

## 4. 필수 포즈 (pose_library.poses) — `pose-sheet.png`

기본 마스코트는 손끝 목표점으로 포즈를 만듭니다. 새 캐릭터도 이 8개가 자연스럽게 나와야 합니다.

| # | 포즈 | 손끝 목표(몸 중심 기준) | 쓰인 곳 |
|---|---|---|---|
| 1 | 기본(대기) | L(-36,60) R(36,60) | 모든 장면 |
| 2 | 오른손 앞으로 뻗기 | R(118,-10) | 레버 당기기(27·실손 비교판, 29번) |
| 3 | 오른손 위로 | R(70,-110) | 가리키기·계기판 두드리기 |
| 4 | 두 손 위로 | L(-80,-70) R(80,-70) | 으쓱("아직 절반이 안 돼요")·환호 |
| 5 | 두 손 앞으로 모음 | L(-10,30) R(10,30) | 물건 들기·나르기(영수증) |
| 6 | 아래로 누르기 | R(80,70), 몸 6px 내려감 | 건반·버튼 누르기(29번) |
| 7 | 시선 옆 + 튀기 | 눈 -4px, 몸 -14px | 걷기(통통 튀며 이동) |
| 8 | 눈 깜빡임 | 눈 세로 0.2배 | 대기 중 생동감 |

- **입이 없으므로 '말하기'는 말풍선**으로 합니다. 말풍선 꼬리는 몸 위쪽 옆(눈 높이 바깥)을 가리킵니다 → 새 캐릭터에 입이 있다면 입 위치 좌표도 알려 주세요.
- 걷기·춤처럼 다리가 움직이는 동작이 필요하면, 막대 인형(`ink-puppet` + 실제 모션캡처 12종: walk, run, climb, march, shuffle, jump, kick, sit, wave, twist, dance_spin, dance_glide) 방식이 별도로 있습니다. 이건 사람형 막대 골격이라 **머리·몸통·팔 2마디·다리 2마디(무릎)** 구조가 필요합니다.

## 5. 표정·감정 (character_design.required_emotions)

기본 마스코트는 **무표정 하나**이고 감정은 몸짓으로만 표현합니다(으쓱 = 아쉬움, 두 손 위 = 환호, 기울기 = 의문). 새 캐릭터에 표정을 추가한다면 눈 모양 변형만 권장:

- 기본(흰 점) · 깜빡임(가는 선) · 놀람(조금 큰 점) · 지침(반쯤 감김)
- 눈은 부위가 분리돼 있어야 바꿔 끼울 수 있습니다.

## 6. 시점 (required_views)

- **정면 1개(필수)** — 지금까지 모든 장면이 정면입니다.
- 옆모습은 선택(걷기 장면을 옆으로 보여줄 때). 추가하면 부위·포즈를 시점마다 다시 만들어야 해서 작업량이 두 배가 됩니다.

## 7. 납품 형식

| 우선순위 | 형식 | 조건 |
|---|---|---|
| **1 (추천)** | **SVG** | `mascot-template.svg` 와 같은 그룹 id(`armL, armR, body, legL, legR, eyeL, eyeR`). 팔·다리는 선(path stroke) 또는 위팔·아래팔이 나뉜 도형. 텍스트는 글자 대신 도형으로 |
| 2 | **PNG 부위별** | 투명 배경, 부위마다 파일 1장, 원본 2배 이상 해상도(몸통 최소 400px 높이). 각 파일의 관절점 픽셀 좌표를 함께 |
| 3 | 포즈별 통짜 그림 | 위 8개 포즈를 각각 한 장씩. 팔 IK 대신 포즈를 갈아 끼움(움직임이 끊겨 보일 수 있음) |

함께 알려 주실 것:
- **캐릭터 이름·성격 한 줄**(무표정 유지 여부 포함)
- **사용 권리**: 직접 그림 / 상업 이용 가능 여부(수익화 채널)
- 잉크 단색을 지킬지, 캐릭터 고유색을 쓸지(고유색이면 ink-theater 색 규칙과 충돌하므로 한 가지 색만 권장)

## 8. 받은 뒤 진행 순서

1. 부위·관절 확인 → 템플릿과 대조해 빠진 부위 보고
2. 엔진에 새 캐릭터 함수(`mascot()` 와 같은 인터페이스: `reachL/reachR`, 위치·크기)로 연결
3. 이 포즈 시트 8종을 새 캐릭터로 다시 렌더해 확인용으로 드림
4. 확인 후 29번(Flow Music) 또는 27번 비교판 한 장면에 넣어 기본 마스코트판과 비교
