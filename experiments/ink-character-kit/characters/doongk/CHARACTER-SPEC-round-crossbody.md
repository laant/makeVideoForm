# 둥근 크로스백 캐릭터 제작 규격

기존 ink-theater 장면에 사용할 새 캐릭터의 디자인과 리깅 기준을 정리한 문서다. 둥근 얼굴과 몸통이 한 덩어리로 이어지고, 작은 몸에 긴 선 팔다리와 작은 크로스백이 달린 형태를 유지한다. 기존 제작 규격의 부위·관절·포즈 구조를 따르되, 캐릭터의 외형은 아래 기준으로 적용한다.

- 캐릭터 이름: 미정
- 성격과 세계관: 미정
- 디자인 기준: 최종 12포즈 이미지 round-crossbody-character-posebook-12-v3.png
- 제작 경위: 사용자가 직접 구상하고 스케치한 캐릭터를 ya를 그리기 도구로 활용해 재현
- 문서 상태: 디자인 기준 확정, 수치·레이어·동작 연결 방식은 구현 제안
- 호환 참고: CHARACTER-SPEC.md, mascot-template.svg, pose-sheet.png

원본 템플릿의 검은 몸·흰 눈·짧은 다리는 기본 마스코트의 디자인이다. 새 캐릭터에는 흰 몸·검정 외곽선·검정 점눈·긴 다리를 적용한다. 부위 id를 유지하더라도 기존 엔진과의 동작 호환은 별도 검증한다.

## 1 그림체 규칙

| 항목 | 새 캐릭터 기준 |
|---|---|
| 색 | 검정 선과 검정 눈, 흰 몸과 흰 배경. 몸 전체를 검정으로 채우지 않는다 |
| 얼굴과 몸통 | 머리와 몸통을 분리하지 않은 둥근 한 덩어리. 별도 목·귀·코·머리카락은 추가하지 않는다 |
| 비율 | 작은 둥근 몸통에 긴 선 팔다리. 곧게 선 기본 자세에서 다리 길이는 몸통 높이와 약 1:1 |
| 눈 | 항상 검정 원형 점 2개. 흰 눈, 선눈, 반달눈, 감은 눈, 큰 눈망울로 바꾸지 않는다 |
| 입 | 기본은 생략. 웃기·놀라기 등 표현에 필요한 포즈에만 작은 입을 사용한다 |
| 팔다리 | 가늘고 둥근 끝을 가진 검정 선. 몸통보다 두꺼워지지 않게 한다. 손가락·신발 등의 별도 도형은 추가하지 않는다 |
| 손발 끝 | 선 끝으로 최소화한다. 기준 이미지의 짧은 끝 굽힘은 허용하되 손발 덩어리를 만들지 않는다 |
| 크로스백 | 몸 앞을 대각선으로 지나는 가는 끈과 작은 가방. 기본 정면에서 가방은 화면 오른쪽 아래에 둔다 |
| 선의 인상 | 단순하고 부드러운 검정 외곽선. 명암·색면·볼터치·질감은 추가하지 않는다 |
| 손그림 떨림 | 엔진에서 적용할 경우 약하게 사용한다. 원형 점눈과 가는 팔다리가 무너지지 않는지 확인한다 |
| 화면 구성 | 기존 장면의 캐릭터·사물 비중 40~60%, 여백 35% 이상을 참고한다. 작은 크기에서도 두 눈과 가방이 구분되어야 한다 |

몸통과 가방은 흰색으로 채워 뒤쪽 선이 비치지 않게 한다. 이는 검은 색면을 사용하는 것이 아니라 외곽선 캐릭터의 흰 내부를 유지하기 위한 처리다. 투명 배경 납품본에서도 몸통과 가방의 흰 내부는 유지한다.

장면의 강조색이 필요한 경우 기존 의미인 주황=흐름·화살표, 빨강=문제·경고, 파랑=좋은 결과를 장면 요소에만 사용한다. 캐릭터 자체에는 적용하지 않는다.

## 2 부위

### 기본 구조

기존 필수 id 7개는 유지하고, 크로스백을 위한 `strap`과 `bag`을 추가한다. `mouth`는 필요한 포즈에서만 보이는 선택 부위다. 머리와 몸통이 한 덩어리이므로 별도 `head`는 만들지 않는다.

좌표는 **몸 중심 (0,0), 오른쪽 +x, 아래쪽 +y**를 사용한다. 이 문서의 L/R은 원본 템플릿과 같은 **화면 기준 왼쪽/오른쪽**이다. 수치는 scale 2 작업좌표에 맞춘 구현 제안값이며, 최종 벡터 원화에서 비율을 맞춰 조정한다.

| id | 형태와 제안 치수 | 기본 레이어 아래→위 | 부모 |
|---|---|---:|---|
| `armL` | 어깨 (-65,-2). 위팔 55 + 아래팔 50. 둥근 선 끝, 굵기 4 | 1 | body |
| `armR` | 어깨 (65,-2). 왼팔과 같은 구조·길이 | 2 | body |
| `legL` | 엉덩이 (-28,62). 허벅지 70 + 종아리 70. 기본은 곧게 편 선, 굵기 4 | 3 | body |
| `legR` | 엉덩이 (28,62). 왼다리와 같은 구조·길이 | 4 | body |
| `body` | 중심 (0,0), 가로·세로 약 140. 흰 채움, 검정 외곽선 4 | 5 | — |
| `strap` | 화면 왼쪽 위 (-62,-30) 부근에서 오른쪽 아래 (35,48) 부근으로 연결되는 곡선. 굵기 3~4 | 6 | body |
| `bag` | 중심 약 (49,52), 너비 34·높이 26. 흰 채움, 검정 외곽선 4. 둥근 작은 가방 | 7 | body |
| `eyeL` | 중심 (-23,-20), 반지름 5.5, 검정 원 | 8 | body |
| `eyeR` | 중심 (23,-20), 반지름 5.5, 검정 원 | 9 | body |
| `mouth` | 중심 약 (0,0), 너비 12~16 이내. 기본 숨김 | 10 | body |

- **팔:** 위팔·아래팔 2마디를 유지한다. 시각적으로는 매끄러운 한 줄로 보이게 연결하고, 손끝 목표점에 따라 팔꿈치를 푼다.
- **다리:** 기본 자세에서는 곧은 선으로 보이지만, 앉기·달리기·쪼그리기를 위해 각 다리에 무릎을 둔다. 부위 id는 `legL`, `legR`을 유지하고 각 그룹 안에서 2마디를 표현한다.
- **크로스백:** 끈과 가방을 분리하되 몸통을 따라 함께 움직인다. 기본적으로 몸통 기울기와 크기 변환을 상속한다. 가방 흔들림은 선택 효과이며 형태를 바꾸지 않는다.
- **부모 관계:** 표의 부모는 변환을 상속할 리그 관계다. SVG에서는 공통 루트 아래에 그룹을 배치해 앞뒤 순서를 조절할 수 있다. `body` 안에 모든 그룹을 중첩해야 한다는 뜻은 아니다.
- **화면 반전:** 가방 위치를 유지할지 좌우 반전할지는 별도 연출 항목이다. 정면 기본형은 화면 오른쪽 가방을 유지한다.

### 가림 처리

기본 자세에서는 팔과 다리의 시작 부분을 흰 몸통 뒤에 놓아 접합부를 정리한다. 두 손으로 물건을 잡거나 얼굴 근처로 손을 가져오는 자세에서는 해당 팔을 몸 앞으로 그릴 수 있어야 한다.

원본처럼 팔을 항상 몸 뒤에 두면 몸 안으로 들어온 손이 가려진다. 따라서 **부위 id는 유지하면서 포즈별 앞뒤 순서를 바꾸는 방식**을 제안한다. 같은 id를 가진 팔을 중복 생성하지 않는다. 가방을 잡는 자세에서는 손이 가방 앞에 보이는지까지 확인한다.

## 3 관절점

아래 위치와 뼈 길이는 기본 정면 자세용 구현 제안이다. 팔·다리를 벌리거나 굽혀도 실제 뼈 길이가 늘어나거나 줄어들지 않게 한다.

| 관절 또는 기준점 | 제안 좌표 | 역할과 제약 |
|---|---|---|
| body center | (0,0) | 전체 이동·기울기·걷기 상하 움직임 기준 |
| shoulderL / shoulderR | (-65,-2) / (65,-2) | 팔 IK 시작점 |
| elbowL / elbowR | 포즈별 IK 계산 | 위팔 55 + 아래팔 50. 자세에 맞는 굽힘 방향을 지정해 갑자기 뒤집히지 않게 한다 |
| hipL / hipR | (-28,62) / (28,62) | 다리 회전·IK 시작점 |
| kneeL / kneeR | 기본 (-28,132) / (28,132) | 허벅지 70 + 종아리 70. 기본 자세에서는 펴고 동작에 따라 굽힌다 |
| footL / footR | 기본 (-28,202) / (28,202) | 발끝 접지·보폭·앉기 자세의 목표점 |
| eyeL / eyeR | (-23,-20) / (23,-20) | 점 모양과 크기를 유지한다. 시선 표현은 두 점을 같은 방향으로 최대 약 4 이동 |
| mouth center | (0,0) 부근 | 필요할 때만 작은 입 표시 |
| bag anchor | (49,52) 부근 | 가방 위치 기준. 몸통을 따라 이동·회전 |
| strap anchors | (-62,-30), (35,48) 부근 | 몸통 위 대각선 끈의 시작·끝 위치 |

기본 몸통 높이 140과 편 다리 길이 140으로 약 1:1 비율을 맞춘다. 이 비율은 엉덩이부터 발끝까지의 편 길이 기준이다. 앉거나 무릎을 굽힌 자세의 화면상 높이는 더 짧아질 수 있다.

팔의 어깨부터 손끝까지 거리는 뼈 길이 합 105 이내로 둔다. 손끝이 목표에 닿지 않으면 팔을 늘리기보다 몸의 위치나 물체의 위치를 조정한다. 다리도 길이 140을 기준으로 같은 원칙을 적용한다.

## 4 필수 포즈

### 기존 장면 연결용 8종

원본 제작 규격의 동작 용도는 유지한다. 다만 8번 깜빡임은 **점눈 유지 대기**로 교체한다. 눈을 선으로 찌그러뜨리는 변형은 사용하지 않는다.

손끝 목표와 몸 움직임은 구현 제안값이다. 목표 좌표는 몸 중심 기준이며, 표에 없는 팔은 기본 대기 위치를 따른다.

| 번호 | 포즈 | 손끝 목표 또는 동작 제안 | 확인할 점 |
|---:|---|---|---|
| 1 | 기본 대기 | L(-88,95), R(88,95) | 둥근 몸, 긴 팔다리, 점눈 2개, 입 없음, 가방 위치 |
| 2 | 오른손 앞으로 뻗기 | R(160,-10) | 레버·물체에 손끝이 닿고 팔 길이가 유지되는지 |
| 3 | 오른손 위로 | R(95,-100) | 가리키기·두드리기. 눈과 가방 형태 유지 |
| 4 | 두 손 위로 | L(-125,-78), R(125,-78) | 어깨·팔꿈치가 자연스럽게 이어지는지. 작은 웃는 입은 선택 |
| 5 | 두 손 앞으로 모음 | L(-12,35), R(12,35) | 두 손과 물체가 몸 앞에 보여야 함. 팔 앞뒤 순서 조정 |
| 6 | 아래로 누르기 | R(140,65), 몸 중심 +6y | 버튼·건반과 접촉. 발은 바닥에 두고 무릎을 조금 굽힘 |
| 7 | 시선 옆과 걷기 상하 움직임 | 눈 2개를 함께 -4x 이동, 몸 중심 최대 -8y 이동 제안 | 눈은 원형 점 유지. 걷기에서는 다리 움직임과 접지를 함께 조정 |
| 8 | 점눈 유지 대기 | 눈의 색·모양·개수·크기를 그대로 유지 | 원본 blink 호출은 새 캐릭터에서 눈 변형 없는 대기로 처리하도록 연결 |

말하기는 말풍선을 기본으로 한다. 말풍선 꼬리는 눈 높이 부근의 몸 바깥쪽을 가리키게 하고, 끈·가방과 겹치지 않도록 배치한다. 입을 사용하더라도 립싱크는 필수 기능이 아니다.

### 디자인 기준 12포즈

최종 12포즈 이미지를 **왼쪽 위부터 행 단위로** 읽는다. 아래 이름은 포즈를 구분하기 위한 설명이며 성격이나 세계관 설정을 뜻하지 않는다.

| 번호 | 이미지 위치 | 포즈 설명 | 디자인 확인점 |
|---:|---|---|---|
| 1 | 1행 1열 | 기본 서 있기 | 입 없음, 기본 비율과 가방 위치 |
| 2 | 1행 2열 | 한 손 들고 인사 | 작은 웃는 입, 반대 팔은 아래로 |
| 3 | 1행 3열 | 걷기 | 벌어진 다리와 자연스러운 팔 |
| 4 | 2행 1열 | 달리기 | 굽힌 무릎, 필요한 경우 작은 둥근 입 |
| 5 | 2행 2열 | 두 손 들고 뛰기 | 팔과 다리를 벌리고 작은 웃는 입 |
| 6 | 2행 3열 | 다리 뻗고 앉기 | 몸통의 둥근 형태와 긴 다리 유지 |
| 7 | 3행 1열 | 쪼그려 앉기 | 양 무릎 굽힘, 몸통이 커지지 않게 함 |
| 8 | 3행 2열 | 머리 위로 팔 뻗기 | 팔은 별도 선으로 읽히고 몸통 외곽선과 혼동되지 않게 함 |
| 9 | 3행 3열 | 다리 교차하고 손을 얼굴 가까이 | 점눈 2개 유지, 팔과 몸의 가림 처리 |
| 10 | 4행 1열 | 한쪽 가리키기 | 팔을 옆으로 뻗고 손끝을 간단히 표현 |
| 11 | 4행 2열 | 몸 숙이기 | 눈과 가방이 몸통 기울기를 따름 |
| 12 | 4행 3열 | 한쪽 다리 들고 춤추기 | 한 무릎을 들고 작은 웃는 입 |

12포즈는 외형과 동작 분위기의 기준이다. 레버 접촉·두 손으로 물건 들기·버튼 누르기처럼 기존 장면에 필요한 자세는 위의 연결용 8종에서 별도로 검수한다. 하나의 포즈 시트를 확인했다고 두 검수가 모두 완료되는 것은 아니다.

전신 움직임에는 다리의 무릎과 발 접지 처리가 필요하다. 원본 문서의 사람형 `ink-puppet` 모션을 사용할 경우, 별도 머리가 없는 이 캐릭터에 맞춰 골격 대응을 확인한다. 기존 모션 12종이 그대로 적용된다고 가정하지 않는다.

## 5 표정과 감정

눈은 모든 감정에서 검정 점 2개를 유지한다. 감정은 팔·다리, 몸의 기울기, 동작의 속도와 멈춤으로 표현하고, 필요한 경우에만 작은 입을 보탠다.

| 상태 | 눈 | 입 | 주된 표현 |
|---|---|---|---|
| 기본 | 검정 원형 점 2개 | 없음 | 곧게 선 몸과 내려놓은 팔 |
| 반가움 | 동일 | 작은 웃는 곡선 선택 | 한 손 인사, 가벼운 몸 움직임 |
| 기쁨 | 동일 | 작은 웃는 곡선 선택 | 두 손 들기, 점프, 춤 |
| 놀람 | 동일 | 작은 원형 입 선택 | 팔 벌리기, 순간 멈춤 |
| 의문 | 동일 | 기본 생략 | 몸 기울이기, 한 손 들어 표현 |
| 지침 | 동일 | 기본 생략 | 몸 숙이기, 팔 내리기, 느린 움직임 |

- 눈 크기 확대, 눈썹 추가, 반쯤 감은 눈, 선눈 깜빡임은 사용하지 않는다.
- 입은 `mouth` 그룹에서 켜고 끄며, 포즈에 필요한 최소한의 크기로 유지한다.
- 눈을 가방끈이나 소품처럼 다루지 않는다. 두 점의 간격과 배치를 일관되게 유지한다.
- 위 감정은 동작 제작용 표현 항목이다. 캐릭터의 고정 성격은 별도로 정한다.

## 6 시점

- **정면은 필수다.** 기본형과 기존 장면 연결용 8종은 정면을 기준으로 제작한다.
- 12포즈의 몸 기울임과 이동 동작에서도 한 덩어리의 둥근 몸과 두 점눈이 유지되게 한다.
- 옆모습·뒷모습은 추가 제작 항목이다. 필요한 경우 눈 2개 규칙과 가방끈의 연속성을 먼저 정한다.
- 옆모습을 별도 설계하기 전에는 옆으로 이동하는 장면에서도 정면 또는 얕은 기울임을 사용한다.

## 7 납품 형식

| 우선순위 | 형식 | 새 캐릭터 기준 |

- 표정 방식: 검정 점눈 2개 고정, 기본 입 없음, 필요한 포즈에만 작은 입

### 납품 점검

- [ ] 기본 7개 부위 id와 끈·가방이 분리되어 있음
- [ ] 입을 사용하는 경우 별도 그룹으로 숨김·표시 가능
- [ ] 몸통 중심, 어깨, 팔꿈치, 엉덩이, 무릎, 발끝 위치 제공

- [ ] 가방은 작게 유지되고, 끈이 두 눈을 지나가지 않음

- [ ] SVG 안내선·관절표시는 별도 `guides`에 두고 출력 시 숨김
- [ ] 디자인 기준 12포즈와 기존 장면 연결용 동작을 각각 검수함

## 8 받은 뒤 진행 순서

아래는 엔진 연결 단계의 작업 순서다.

1. **벡터 원화와 부위 확인**  
   최종 12포즈의 외형을 기준으로 부위 id, 끈·가방·입 분리 여부를 확인한다. 실제 원화에 맞춰 제안 좌표와 뼈 길이를 확정한다.

2. **새 캐릭터 함수 연결**  
   기존 `mascot()`의 호출 방식을 확인하고 위치·크기와 `reachL/reachR` 제어를 맞춘다. 흰 몸과 검정 눈, 포즈별 팔의 앞뒤 순서, 눈 깜빡임 비활성화, 다리 2마디 제어를 새 캐릭터 구현에 반영한다.

3. **포즈와 접촉 검수**  
   연결용 8종을 렌더해 손끝과 물체 접촉, 몸 안에 가려지는 손, 다리 접지, 가방과 팔의 겹침을 확인한다. 눈은 8번에서도 점 2개를 유지한다. 이어서 디자인 기준 12포즈의 비율과 인상을 확인한다.

4. **실제 장면 비교**  
   원본 문서에 지정된 29번 Flow Music 또는 27번 비교판 중 한 장면에 적용해 확인한다. 기존 사물 좌표에 맞추려고 팔다리를 늘리기보다 캐릭터 위치·크기 또는 접촉 목표를 조정한다.

5. **최종 확정**  
   이름·성격·사용 권리 확인 항목을 채우고, 확정된 관절 좌표·레이어 규칙·포즈 데이터를 최종 납품본에 반영한다.
