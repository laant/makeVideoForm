## B. ink-theater (코드 렌더, 비용 0)

**콘셉트:** 흰 바탕 검은 잉크 손그림 세계에서 무표정 마스코트가 엉뚱한 기계를 조작해 개념을 '연기'한다. 선은 손그림처럼 살짝 떨림(boil).

| 장면 | 마스코트의 연기 |
|---|---|
| 1 | 마스코트가 영수증을 들고 큰 폰 모양 기계 앞에 선다 → 레버 세 개(네이버 지도·네이버페이·토스 이름표)를 차례로 당김(이름 나올 때) → 영수증을 투입구에 넣으면 기계 안에서 끝까지 굴러가 '끝까지'에 체크 램프 |
| 2 | 지금: 마스코트가 영수증을 들고 폰 → 먼 건물(실손24 사이트)까지 사다리를 넘어 걸어감(mocap walk/climb) → 10월 7일: 폰과 보험사 사이에 컨베이어가 깔려 영수증이 바로 감. 마이데이터: 깔때기(hopper)에서 입력칸 네 개가 차례로 채워짐 |
| 3 | 마스코트가 계기판(gauge)을 두드림 → 바늘이 47.7%에 멈추고 50% 눈금에 못 미침 → 어깨를 으쓱(gesture) "아직 절반이 안 돼요" |

- 글꼴: 한글 손글씨 OFL 글꼴(나눔손글씨 펜) 전체 파일 내장 — README 의 글꼴 함정(부분 글꼴) 회피.
- 렌더: HyperFrames(HTML/SVG + GSAP 정지 타임라인). 결정론 규칙 준수.
- 하단 자막 없음, 화면 문구는 말풍선·이름표·계기판 숫자로.
